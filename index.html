04 / PLAYBOOK

三家打法对比

买的设备不同，本质是运营商对「AI 时代自己是谁」的答案不同。

中国移动

中心大集群 · 训练 + 推理双轮
  • 超节点 10,048 卡 / 33.6 亿，全昇腾 CANN 生态，整机柜预集成交付
  • 推理型服务器 7,499 台 / 50+ 亿，明确「中训边推」战略
  • H1 招标 92.56 亿，占三家总量近六成
  • 定位：主业重构为「通信 + 算力 + 智能」三服务，设集团级 Token 办公室
一句话：用集团级集采把国产 AI 底座一次买够，抢占「算力国家队」生态位。

中国电信

接入侧融合 · 全光 + 算力下沉企业
  • 全光组网接入算力一体机累计约 3.3 万台，是唯一破万的单品类
  • FTTR-B + 算力卡融合形态，单价 2-5 万元/台，走量逻辑
  • 智算 91 EFLOPS + 「息壤」调度平台，14 区域 + 48 行业节点
  • 探索 PCO / EPCO 建设运营模式（芜湖 120 个月运维期）
一句话：把算力做成「宽带套餐」卖进企业房间——运营商里最接近消费电子打法的玩家。

中国联通

边缘节点 · 轻资产 + 调度
  • 「AI 边缘一体机」列入五大智算产品线，无集团级大单，省级分散采购
  • 智算 45 EFLOPS；OISA 卡间互联 + GSE 机间互联自研协议
  • 承建国家算力互联互通河北节点，8 个调度平台落地
  • 算力投资 >100 亿（35% 占比），绝对额最小但占比最高之一
一句话：不硬拼规模，用「调度 + 边缘」找差异化卡位——钱包最紧，姿势最巧。

06 / TAKEAWAY

五个值得记住的趋势

对算力设备厂商而言，2026 年的运营商市场给出了清晰信号。

TREND 01
形态收敛：整机柜/预集成成为默认

移动超节点要求工厂预集成、整机柜交付；电信一体机把 FTTR、服务器、算力卡打包成单台设备。「散件拼装」的时代在运营商市场结束了。

TREND 02
国产化不再是加分项，是入场券

移动超节点 100% 昇腾 CANN；电信一体机 ARM 标包全落在华为生态。海外芯片在运营商集采中已实质出局。

TREND 03
推理 workload 超过训练

移动一年期推理集采 7,499 台 / 50+ 亿，规模与超节点相当；集团明确「从训练为主转向推理为主」。边缘推理一体机是增量战场。

TREND 04
接入侧是下一个放量口

电信全光组网一体机累计 3.3 万台、单台 2-5 万元——验证了「光纤到户 + 本地算力」的企业侧需求真实存在且正在放量。

TREND 05
集采报价趋同，利润透明化

移动超节点五家报价最大差仅 1,100 万 / 20.7 亿（0.5%）。硬件差价归零，竞争转向交付、能效与生态适配。

◎
对本项目（高阶网关 FTTO + 算力模块）的直接映射
电信「全光组网接入算力一体机」累计 3.3 万台的采购节奏，证明 FTTx 管道 + 算力模块的融合形态已被运营商总部层面验证并接受；移动「中训边推」与联通「AI 边缘一体机」则说明推理算力正在向边缘节点下沉。三家路径不同，但都在为「算力离用户更近」投票——这正是高阶网关的生态位。
